How fast? In which direction?

Set distance and time to calculate average speed. Add a direction to describe average velocity when displacement is known.

AVERAGE SPEED5 m/s
AVERAGE VELOCITY5 m/s East*

*Assumes displacement magnitude equals the distance setting, except when zero displacement is selected. In a real journey with turns, use actual displacement for velocity.

Remember

Speed tells how much distance is covered per unit time. It is a scalar.

Velocity tells displacement per unit time in a stated direction. It is a vector.
