# Interactive Teaching Labs (Classes 6–8)

A collection of classroom teaching resources combining presentations, physical demonstrations, interactive simulations, animations, and assessment. The materials were developed iteratively based on classroom experience.

## Contents

- **Class 6 — Simple Machines:** interactive lab, presentation, and supporting teaching materials.
- **Class 7 — Force and Motion:** interactive lab, presentations, GIF animations, and supporting notes.
- **Class 8 — Electricity and Magnetism:** interactive adventure and presentation.
- **Science MCQ Assessment Portal:** a standalone HTML assessment tool.

## How to use

1. Download or clone this repository.
2. Open each class folder and read its `README.txt` or `START_HERE.html` if present.
3. For HTML labs, open the relevant `index.html` or `START_HERE.html` in a modern browser. Many activities are designed to run locally; behaviour should be checked on the target classroom computers before teaching.
4. Use the presentations alongside demonstrations and guided student exploration. Start with a physical experiment where safe and practical, ask students to predict, let them explore, and invite them to explain the pattern before giving the formal conclusion.

## Classroom reflection

Teacher-reported observations from initial use:

- Class 6: the Simple Machines demonstration worked particularly well and students showed enthusiasm.
- Class 7: students could distinguish scalar and vector quantities; the Earth–Moon mass-and-weight example was especially effective. Assessment reports helped identify students and concepts needing further support.
- Class 8: the Electricity and Magnetism resource is still a work in progress. Some ammeter/voltmeter elements are illustrative rather than functional measurement tools, and the geographical-versus-magnetic-pole visualisation needs further refinement and animation.

These are qualitative classroom observations, not a controlled study or proof of long-term learning gains.

## Important limitations

- Interactive resources are teaching aids and should not replace physical experiments where those are safe and practical.
- Some animations are qualitative illustrations, not full physics simulations. Do not treat illustrative instrument displays as calculated measurements.
- Test every activity on the classroom computers before use.
- Assessment results may contain student information. Do not commit real student names, scores, or identifiable records to this public repository.

## Suggested teaching sequence

**Physical demonstration → prediction → concise explanation → simulation exploration → student observation and reasoning → formal conclusion → short assessment.**

## Project status

This repository is an evolving teaching project. Features and scientific models may be refined as they are tested. Please check the class-specific notes for additional details.
